Getting Started with NeuraChat

NeuraChat is a full-stack AI chatbot powered by Google Gemini 2.5 Flash. Here is everything you need to start using it.

  1. Visit the live app and click “Get Started”
  2. Create a free account — no credit card required
  3. You land on the chat interface automatically
  4. Type any message and press Enter or click Send
  5. Your chats are automatically saved in the sidebar
  6. Access previous conversations anytime from chat history
NeuraChat runs on Render free tier. The first request after inactivity may take up to 50 seconds to respond. This is normal.

System Architecture

How NeuraChat works under the hood

Browser

→
Gemini API
↕
SQLite DB

Frontend

Vanilla JS, Tailwind CSS, GSAP. Served as static HTML files by Flask.

Backend

Python Flask handles authentication, chat routing, profile management, and membership enforcement. All routes prefixed /api/.

AI Engine

An agentic engine wraps Gemini 2.5 Flash. It detects intent, tracks topic and depth, and passes full conversation history on every request.

Database

SQLite with 5 tables — users, chats, messages, profiles, membership. Auto-generated on startup.

Security

  • Passwords hashed using Python scrypt via hashlib. Never stored in plain text.

  • Sessions managed server-side via Flask sessions. No JWT tokens exposed to the client.

  • All markdown from AI responses is sanitized through DOMPurify before rendering. Prevents XSS injection.

  • All /api/ routes except /register and /login require a valid session. Unauthorized requests return 401.

Authentication

How user auth works in NeuraChat

POST /api/register

Creates new user, hashes password, sets session

POST /api/login

Verifies credentials, sets session cookie

POST /api/logout

Clears server-side session

GET /api/auth/status

Returns authentication state

Request example

POST /api/register
{
  "username": "ankush",
  "email": "ankush@example.com",
  "password": "yourpassword"
}

Response example

{ "success": true, "user_id": "abc123" }

Messages

How chat messages are sent and received

POST /api/chat

Sends a user message and returns the AI response

Request

{
  "message": "What is machine learning?",
  "chat_id": "chat_abc123"
}

Response

{
  "response": "Machine learning is...",
  "limit_reached": false
}
  • chat_id links the message to a saved conversation
  • Full conversation history is loaded server-side on each request
  • Responses are markdown formatted — rendered client-side via marked.js
  • Free tier returns limit_reached: true after 50 messages

How history works

On every message, the full conversation history is passed to Gemini as a structured contents array. Each message includes role (user or model) and content. This gives Gemini full context of the conversation.

Limitations

  • Subject to Google Gemini API rate limits on free tier
  • 10 requests per minute, 250 requests per day on free tier
  • First response after cold start may be slower

Storage

How data is stored in NeuraChat

Database: SQLite (neurachat.db)

users

id, username, email, password_hash, plan, message_count, created_at

chats

id, user_id, title, created_at

messages

id, chat_id, role, content, created_at

profiles

user_id, display_name, bio, avatar_url

membership

user_id, plan, message_count, reset_date

NeuraChat runs on Render free tier. The SQLite database resets on each redeploy. For persistent storage, add a Render Disk.
