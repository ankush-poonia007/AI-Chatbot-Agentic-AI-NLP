Installation

Install the NeuraChat core package using your preferred package manager. We recommend using our optimized CLI for the best experience.

npm install @neurachat/core
# or using yarn
yarn add @neurachat/core

Your First Connection

Initialize the NeuraClient with your encrypted workspace token to begin processing neural requests.

import { NeuraClient } from '@neurachat/core';

// Initialize client with futuristic backdrop
const client = new NeuraClient({
  apiKey: process.env.NEURA_KEY,
  environment: 'production',
  latencyMode: 'ultra-low'
});

async function startNeuralLink() {
  const response = await client.generate({
    prompt: "Analyze system diagnostics",
    temperature: 0.7
  });
  
  console.log(response.data);
}
